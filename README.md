# drink_game

最大4人で遊べる、オンライン対戦のパーティミニゲーム集（Unity）。
部屋を作って6文字のルームIDを共有するだけで、離れた友達とすぐに遊べます。

## 主な機能
- ルームの作成と参加（Unity Relay を使うので、ポート開放は不要）
- 4席のロビー（一人称視点。席ごとに色分けし、他のプレイヤーの視線も同期）
- 表示名の入力（次回起動時も保持）
- ミニゲーム：神経衰弱

## 技術スタック
| 項目 | 内容 |
|---|---|
| エンジン | Unity 6000.3.10f1 / URP |
| 通信 | Netcode for GameObjects 2.13（ホスト型） |
| 接続 | Unity Gaming Services: Relay + Authentication（匿名） |
| 入力 | Input System |
| UI | uGUI + TextMeshPro |

## 起動方法
> ⚠️ **必ず `Assets/Scenes/NetworkBase.unity` から再生してください。**
> NetworkManager がこのシーンにあるため、Title や Lobby から直接再生すると通信できません。

- 1台で複数人の動作を確認する：`Window > Multiplayer > Multiplayer Play Mode` で仮想プレイヤーを追加する
- ホスト：Lobby で「作成」を押し、表示されたルームIDを相手に伝える
- 参加者：「参加」を押してルームIDを入力する
- ホストが「ゲーム開始」を押すと、全員が神経衰弱に移動する

## シーンの流れ
NetworkBase → Title → Lobby ⇄ MemoryGame

| シーン | 役割 |
|---|---|
| NetworkBase | NetworkManager / RelayManager を置く起動用シーン |
| Title | タイトル画面 |
| Lobby | ルームの作成・参加、席への配置 |
| MemoryGame | 神経衰弱 |

## ディレクトリ構成
```
Assets/Scripts/
├── Lobby/        ロビー、プレイヤー、接続 UI、退出処理
├── MemoryGame/   神経衰弱（Card / MemoryGameManager）
├── SampleScene/  Relay 接続（RelayManager）と検証用コード
└── Title/        シーン遷移
```

## 設計のポイント
- **サーバー権威**：スコア・手番・カードの状態はサーバーだけが書き込み、クライアントは RPC で要求を送るだけ
- **カード位置は通信しない**：円の設定値と ServerTime から、各端末が同じ位置を計算する
- **プレイヤーはシーンをまたいで残る**：シーンに合わせて、カメラと表示を自分で切り替える
